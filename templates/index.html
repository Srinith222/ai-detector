      Trained classifier

      A model trained on real and generated images scores the whole picture. This is the strongest signal, and it only runs when a model is installed on the server.

      Pixels and noise

      Camera sensors leave grain and generators often don't. We also scan the frequency pattern for the repeating marks that upscaling can leave behind.

      File history

      Some tools write their name into the file, and cameras write their settings. When either is there, it counts. When it isn't, we ignore it.

      No detector is certain. Screenshots, heavy compression and edits can fool every check, and new generators appear all the time. Treat a result as evidence, not proof.
